# Example itineraries

These are **curated drafts generated by this repository's own functions** — not bookable plans, not
quotes and not live availability. Picks come from `buildItineraryWithStatus`, feasibility counts from
`validatePlan`, and budget ranges from `estimateBudget` in [`lib/itineraries.ts`](../lib/itineraries.ts)
and [`lib/feasibility.ts`](../lib/feasibility.ts). Curated hours were checked on 2026-11-24; verify
hours, prices and travel times before any trip. No stop is invented and no day is repeated.

Reproduce all three plans from the repository root (PowerShell needs `npm.cmd`; on POSIX use `npx`):

```bash
npx.cmd tsx -e "import { CITIES, buildItineraryWithStatus, estimateBudget } from './lib/itineraries'; import { validatePlan, dateForDay, WEEKDAY_NAMES, weekdayForDate } from './lib/feasibility'; const cases = [{id:'tokyo',start:'2026-11-27',days:3,interests:['food','culture'],travellers:2},{id:'lisbon',start:'2026-11-30',days:2,interests:['nature','relax'],travellers:2},{id:'bali',start:'2026-11-28',days:2,interests:['nature','relax'],travellers:2}]; for (const c of cases) { const city = CITIES.find(x=>x.id===c.id)!; const built = buildItineraryWithStatus(city,c.days,c.interests as any,c.start); const check = validatePlan(built.days,c.start); const budget = estimateBudget(city,built.days.length,c.travellers); console.log(JSON.stringify({city:c.id,start:c.start,days:c.days,interests:c.interests,travellers:c.travellers,limited:built.limited,budget,feasibleDays:check.feasibleDays,hard:check.totalHard,advisories:check.totalWarnings-check.totalHard,advisoryText:check.days.flatMap(d=>d.advisories),days:built.days.map((d,i)=>({day:d.day,date:dateForDay(c.start,i),weekday:WEEKDAY_NAMES[weekdayForDate(dateForDay(c.start,i))],morning:d.morning.title,afternoon:d.afternoon.title,evening:d.evening.title}))},null,2)); }"
```

## Example 1 — Tokyo, food + culture

**Input:** city Tokyo (`tokyo`), start date `2026-11-27`, 3 days, interests Food + Culture, 2
travellers. This is the same input as the deterministic walkthrough fixture
`artifacts/walkthrough/01-input.json`.

| Day | Date (weekday) | Morning | Afternoon | Evening |
|---|---|---|---|---|
| 1 | 2026-11-27 (Friday) | Tsukiji outer market breakfast | Yanaka backstreets | Yakitori alley, Shinjuku |
| 2 | 2026-11-28 (Saturday) | Kappabashi kitchen street | Shibuya to Daikanyama walk | Golden Gai bar hop |
| 3 | 2026-11-29 (Sunday) | Meiji Jingu forest walk | TeamLab Planets | Onsen and early night |

**Feasibility:** 3 / 3 days feasible; 0 hard conflicts; 0 advisories. The Sunday closures of Tsukiji
and Kappabashi are avoided by placing them on Friday and Saturday.

**Budget:** 696–1175 USD-equivalent for 2 travellers over 3 days (on-ground estimate; flights
excluded, no FX conversion). Export: `artifacts/walkthrough/02-plan.md`.

## Example 2 — Lisbon, nature + slow travel

**Input:** city Lisbon (`lisbon`), start date `2026-11-30`, 2 days, interests Nature + Slow travel
(`relax`), 2 travellers. A Monday start exercises the weekday-closure check: LX Factory, Belém and
Cais do Sodré are curated as closed on Mondays.

|---|---|---|---|---|
| 1 | 2026-11-30 (Monday) | Miradouro da Graça sunrise | Sintra day trip | Bairro Alto rooftop |
| 2 | 2026-12-01 (Tuesday) | LX Factory browse | Belém and the river | Cais do Sodré seafood |

**Feasibility:** 2 / 2 days feasible; 0 hard conflicts; 0 advisories.

**Budget:** 336–567 USD-equivalent for 2 travellers over 2 days (on-ground estimate; flights
excluded, no FX conversion).

## Example 3 — Bali, nature + slow travel (advisory shown)

**Input:** city Bali (`bali`), start date `2026-11-28`, 2 days, interests Nature + Slow travel
(`relax`), 2 travellers. Bali's curated dataset supports at most 2 days.

| Day | Date (weekday) | Morning | Afternoon | Evening |
|---|---|---|---|---|
| 1 | 2026-11-28 (Saturday) | Tegallalang terrace walk | Scooter to a hidden beach | Beach club sunset |
| 2 | 2026-11-29 (Sunday) | Sunrise surf lesson | Canggu café afternoon | Jimbaran seafood grill |

**Feasibility:** 2 / 2 days feasible; 0 hard conflicts; **1 advisory**:

> Afternoon: 75 min transfer to Scooter to a hidden beach. Long but possible — check live transit
> before you go.

The advisory is a haversine straight-line estimate with a fixed urban speed and buffer, not a live
transit result; it does not make the day infeasible.

**Budget:** 250–421 USD-equivalent for 2 travellers over 2 days (on-ground estimate; flights
excluded, no FX conversion).

## Limited-rebuild example — Tokyo, Day 3 on Sunday

**Input:** the Tokyo plan above; press “Rebuild this day” on Day 3 (`2026-11-29`, Sunday).

`rebuildDayWithStatus(city, days, 2, ['food','culture'], '2026-11-27')` returns
`limited: true, changed: true`. The morning slot is left unchanged because both other curated
morning stops, *Tsukiji outer market breakfast* and *Kappabashi kitchen street*, have curated
`closedDays: [0]` (Sunday) — there is no open alternative for that slot on that date. The other two
slots are rebalanced, and the plan still has 3 days with no duplicate stop and 0 hard conflicts /
0 advisories after the rebuild:

| Slot | Before | After |
|---|---|---|
| Morning | Meiji Jingu forest walk | Meiji Jingu forest walk (unchanged — no open alternative) |
| Afternoon | TeamLab Planets | Yanaka backstreets |
| Evening | Onsen and early night | Golden Gai bar hop |

Because `limited` is true, `components/planner/Planner.tsx` shows this exact notice above the days:

> No open alternative exists in the curated set for this date, so that slot was left unchanged. No
> extra attraction was invented.

Reproduce the limited case:

```bash
npx.cmd tsx -e "import { CITIES, buildItineraryWithStatus, rebuildDayWithStatus, SLOTS } from './lib/itineraries'; import { validatePlan, dateForDay, WEEKDAY_NAMES, weekdayForDate } from './lib/feasibility'; import { VENUE_META } from './lib/venue-meta'; const city=CITIES.find(c=>c.id==='tokyo')!; const start='2026-11-27'; const built=buildItineraryWithStatus(city,3,['food','culture'],start); const r=rebuildDayWithStatus(city,built.days,2,['food','culture'],start); const wd=weekdayForDate(dateForDay(start,2)); const post=validatePlan(r.days,start); console.log(JSON.stringify({date:dateForDay(start,2),weekday:WEEKDAY_NAMES[wd],limited:r.limited,changed:r.changed,before:SLOTS.map(s=>built.days[2][s].title),after:SLOTS.map(s=>r.days[2][s].title),morningAlternatives:city.items.filter(i=>i.slot==='morning' && i.title!==built.days[2].morning.title).map(i=>({title:i.title,closedDays:VENUE_META[i.title].closedDays,closedOnDate:VENUE_META[i.title].closedDays.includes(wd)})),days:r.days.length,hard:post.totalHard,advisories:post.totalWarnings-post.totalHard},null,2));"
```

## Scope of these examples

These drafts are deterministic outputs of a prototype over a finite curated dataset. They are **not
bookable**: no hotel, activity, seat or price is held, no live availability is checked, and no
payment is taken. “Map ↗” and the handoff links open third-party search pages. See
[`docs/CASE_STUDY.md`](CASE_STUDY.md) for the full verification matrix and
[`docs/ARCHITECTURE.md`](ARCHITECTURE.md) for where curated facts and estimates enter the engine.
